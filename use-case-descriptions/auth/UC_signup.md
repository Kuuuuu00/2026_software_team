# Use case description: 회원 가입

**Precondition**: 사용자는 시스템에 접속한 상태이며 아직 로그인하지 않은 상태이다.

**Basic Flow**:

| Actor Action | System Response |
|---|---|
|   | 1. ID, 비밀번호, 이름, 전화번호, 이메일 입력 필드가 포함된 회원가입 화면을 표시한다 |
| 2. 모든 필수 항목을 입력하고 [가입하기] 버튼을 누른다 |   |
|   | 3. 신규 회원 정보를 등록하고 가입 완료 메시지를 표시한다 |

**Alternative Courses**:
- 3a. 필수 항목 중 누락된 항목이 있는 경우: 시스템은 누락된 필드를 안내한다. Actor는 단계 2로 돌아간다.
- 3b. 입력한 ID가 이미 등록되어 있는 경우: 시스템은 "이미 사용 중인 ID입니다" 안내를 표시한다. Actor는 단계 2로 돌아가 다른 ID를 입력한다.

**Postcondition**: 새로운 회원 계정이 시스템에 등록된다. 사용자는 등록한 정보로 로그인할 수 있는 상태가 된다.
