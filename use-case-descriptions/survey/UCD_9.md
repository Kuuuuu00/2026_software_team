# Use case description: 설문 응답

| Actor Action | System Response |
|---|---|
| 1. 설문 상세 정보 조회 화면에서 [응답] 버튼을 누른다. |   |
|   | 2. 응답 화면(설문 문항과 응답 항목)을 표시한다. |
| 3. 설문 문항에 대한 응답 항목을 선택하고 [응답] 버튼을 눌러 완료한다. |   |
|   | 4. 설문 응답 내용이 저장된다. |

**Alternative Courses**:
- 4a. 모든 설문 문항에 대해 응답하지 않았을 경우 : 시스템은 "응답 항목이 없습니다" 안내를 표시한다. actor는 단계3으로 돌아간다.
