# Use case description: 설문 조회

| Actor Action                                 | System Response                                                     |
| -------------------------------------------- | ------------------------------------------------------------------- |
| 1. 설문 리스트 조회 메뉴를 선택한다          |                                                                     |
|                                              | 2. 등록된 모든 설문 항목이 포함된 설문 리스트 화면을 표시한다       |
| 3. 조회하고자 하는 특정 설문 항목을 선택한다 |                                                                     |
|                                              | 4. 선택한 설문 항목의 응답 항목 등 상세 내용을 팝업 창으로 표시한다 |

**Alternative Courses**:

- 4a. Actor가 설문 항목 우측의 [X] 버튼을 클릭한 경우: 시스템은 "삭제 한 설문은 되돌릴 수 없습니다. 정말 삭제하시겠습니까?" 확인 팝업을 [삭제], [취소] 버튼과 함께 표시한다.
  - 4a-1. Actor가 [삭제] 버튼을 클릭한 경우: 시스템은 해당 설문을 삭제하고 갱신된 설문 리스트를 표시한다.
  - 4a-2. Actor가 [취소] 버튼을 클릭한 경우: 시스템은 확인 팝업을 닫고 설문 리스트 화면을 그대로 유지한다.
- 2a. 등록된 설문이 하나도 없는 경우: 시스템은 빈 설문 리스트와 함께 [+ 등록하기] 버튼을 표시한다.
