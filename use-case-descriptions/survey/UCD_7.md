# Use case description: 설문 검색

| Actor Action | System Response |
|---|---|
|   | 1. 검색 키워드를 입력할 수 있는 검색칸과 선택된 진행 상태를 보여주는 진행 상태 칸을 표시한다. |
| 2. 진행 상태를 선택하고 검색 키워드를 입력한다. |   |
|   | 3. 조건에 맞는 설문 리스트를 표시한다. |

**Alternative Courses**:
- 3a. 검색 키워드를 입력하지 않은 경우: 시스템은 모든 설문 리스트를 표시한다.
- 3b. 검색 키워드에 일치하는 설문이 없을 경우 : 시스템은 "키워드와 일치하는 설문이 없습니다. 검색 키워드를 다시 입력해주십시오."라는 안내 문구를 띄운다. actor는 2로 돌아간다.
