# Use case description: 로그아웃

| Actor Action                                | System Response                                                             |
| ------------------------------------------- | --------------------------------------------------------------------------- |
| 1. 화면 우측 상단의 프로필을 클릭한다      |                                                                             |
|                                             | 2. [로그아웃] 버튼이 포함된 드롭다운 메뉴를 표시한다                        |
| 3. [로그아웃] 버튼을 클릭한다               |                                                                             |
|                                             | 4. "로그아웃 하시겠습니까?" 확인 팝업을 [예], [아니요] 버튼과 함께 표시한다 |
| 5. [예] 버튼을 클릭하여 로그아웃을 확정한다 |                                                                             |
|                                             | 6. 사용자 세션을 종료하고 로그아웃 처리 후 메인 화면으로 이동한다           |

**Alternative Courses**:

- 5a. Actor가 [아니요] 버튼을 클릭한 경우: 시스템은 확인 팝업을 닫고 로그인 상태를 유지한 채 이전 화면으로 돌아간다.
