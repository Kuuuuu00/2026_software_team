# Use case description: 설문 응답 조회

| Actor Action | System Response |
|---|---|
| 1. 응답한 설문 메뉴를 선택한다 |  |
|  | 2. Actor가 응답한 설문의 제목이 나열된 목록을 표시한다 |
| 3. 조회하고자 하는 설문의 [조회] 버튼을 클릭한다 |  |
|  | 4. 선택한 설문의 응답 내용, 응답 일시를 표시한다 |

**Alternative Courses**:
- 4a. Actor가 진행 중인 설문을 조회한 경우 : 추가적으로 [수정], [응답 취소] 버튼을 표시한다.
  - 4a-1. Actor가 [수정]을 선택한 경우 : Actor가 응답 수정 화면으로 이동한다.
  - 4a-2. Actor가 [응답 취소]를 선택한 경우 : 해당 설문을 목록에서 삭제한다.
- 4b. Actor가 종료된 설문을 조회한 경우: [수정], [응답 취소] 버튼을 표시하지 않는다
