# Use case description: 응답한 설문 조회

| Actor Action | System Response |
|---|---|
| 1. 응답한 설문 메뉴를 선택한다 |  |
|  | 2. Actor가 응답한 설문의 목록을 표시한다 |
| 3. 조회하고자 하는 설문의 [조회] 버튼을 클릭한다 |  |
|  | 4. 선택한 설문의 제목, 응답 내용, 응답 일시를 표시한다 |

**Alternative Courses**:
-  4a. 선택한 설문이 진행 중인 경우 : 추가적으로 [수정], [응답 취소] 버튼을 함께 표시한다.
    - 4a-1. Actor가 [응답 취소]를 클릭한 경우 :
      - (1) 응답 취소 확인 메시지를 표시한다
      - (2) Actor가 [확인]을 클릭한다
      - (3) 해당 설문의 응답을 취소하고, 갱신된 응답 목록을 표시한다
    - 4a-2. Actor가 [수정]을 클릭한 경우 : 설문 응답 수정 UC로 확장된다.
- 4b. 선택한 설문이 종료된 경우 : [수정], [응답 취소] 버튼은 표시하지 않는다.
