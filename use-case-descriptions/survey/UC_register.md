# Use case description: 설문 등록

| Actor Action | System Response |
|---|---|
| 1. 설문 리스트 화면에서 [+ 등록하기] 버튼을 클릭한다 |   |
|   | 2. 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작/마감 시각 입력 필드가 포함된 설문 등록 화면을 표시한다 |
| 3. 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각을 입력한다 |   |
| 4. [등록하기] 버튼을 클릭한다 |   |
|   | 5. 신규 설문 정보를 등록하고 등록 완료 메시지를 표시한 뒤 설문 리스트 화면으로 이동한다 |

**Alternative Courses**:
- 5a. 필수 항목 중 누락된 항목이 있는 경우: 시스템은 누락된 필드를 안내한다. Actor는 단계 3으로 돌아가 누락된 항목을 입력한다.
- 5b. 설문 마감 시각이 설문 시작 시각보다 이전인 경우: 시스템은 "설문 마감 시각은 시작 시각 이후여야 합니다" 안내를 표시한다. Actor는 단계 3으로 돌아가 시각을 다시 입력한다.
